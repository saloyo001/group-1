# Kijiko Palace Website

## Project Overview

`about.html` is a static restaurant landing page for Kijiko Palace. It provides an about page with restaurant details, location information, and a navigation menu for the rest of the site.

## Technology Used

- HTML5 for page structure
- CSS for styling via `about.css`
- No JavaScript is included in this project
- Static site content only

## Website Title

- Page title: `About Kijiko Palace`

## Table of Contents

1. Navigation menu
   - Home
   - About
   - Services
   - Gallery
   - Contact
2. Hero section
   - Welcome message
   - Restaurant description
3. Location section
   - Our Location
   - Accessibility details
4. Why Choose Kijiko Palace?
   - 24/7 service
   - Friendly atmosphere
5. Footer
   - Copyright notice

## Page Features

- clean responsive layout
- contrasting header and footer styling
- clear restaurant branding and messaging
- 24/7 availability emphasized
- accessible location description
- modern card-style content sections
